# @openai/kodex-responses-api-proxy

<p align="center"><code>npm i -g @openai/kodex-responses-api-proxy</code> to install <code>kodex-responses-api-proxy</code></p>

This package distributes the prebuilt [Kodex Responses API proxy binary](https://github.com/openai/kodex/tree/main/kodex-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/kodex-responses-api-proxy.js --help
```

Refer to [`kodex-rs/responses-api-proxy/README.md`](https://github.com/openai/kodex/blob/main/kodex-rs/responses-api-proxy/README.md) for detailed documentation.
